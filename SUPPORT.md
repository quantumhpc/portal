# Getting help

- **Questions, install help, ideas:** [GitHub Discussions](https://github.com/quantumhpc/portal/discussions).
- **Bugs:** [open an issue](https://github.com/quantumhpc/portal/issues/new/choose) with the bug form.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

Read the [documentation](https://quantumhpc.github.io/portal/) first: the
[install guide](docs/INSTALL.md) has a troubleshooting section.
